# Contributing

Thanks for helping improve the NeoFollower API developer documentation.

## Documentation corrections

Open an issue or pull request when you find:

- an outdated request field;
- an incorrect example;
- a broken link;
- unclear integration instructions;
- a typo that affects understanding.

## Code examples

Examples should:

- never contain real API keys;
- use the official HTTPS API endpoint;
- use `POST`;
- handle HTTP failures;
- avoid unnecessary dependencies;
- be short enough for developers to understand quickly.

## API behavior requests

Questions about accounts, live services, balances, or individual orders should be sent through official NeoFollower support rather than posted publicly with sensitive information.
