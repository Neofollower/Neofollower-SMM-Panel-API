# Security Policy

## API keys

Never publish a NeoFollower API key in:

- Git commits
- GitHub issues
- pull requests
- screenshots
- browser-side JavaScript
- public logs

If you accidentally expose a key, treat it as compromised and replace it through the appropriate NeoFollower account/support process.

## Reporting documentation or example security issues

If an example in this repository encourages unsafe credential handling or contains a security defect, report it privately through NeoFollower's official support channel when disclosure would expose users to risk.

Do not include live credentials in a report.
